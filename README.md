# Google Antigravity — Полная русская локализация

Качественная, полная и компактная русификация интерфейса десктопного приложения **Google Antigravity** (Windows).  
Протестировано на версии **2.11.0**.

---

## Что переведено

- **715+ терминов и фраз интерфейса:**
  - Все вкладки настроек: Общие, Приложение, Внешний вид, Модели и лимиты, Браузер, Уведомления, Аккаунт.
  - Профили безопасности, статистика токенов, навыки и правила MCP.
  - Панель изменённых файлов (Uncommitted, Agent Edits, Branch).
  - Все плейсхолдеры поиска и полей ввода.
- **Системные меню Electron:** Файл, Правка, Вид, Окно, Справка, трей и диалоги выхода.
- **Сплеш-экран:** заменён на «Загрузка Antigravity...».
- **Компактная типографика:** лаконичные формулировки без раздутых переносов.
- **Сохранение данных:** проекты, история, ключи API и логины не затрагиваются.
- **Защита от автообновлений:** фоновый `autoUpdater` отключён.

## Быстрый старт

### Установка одной командой (PowerShell)

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/SPIDIKSY/antigravity-ru/main/install.ps1 | iex
```

Скрипт автоматически загрузит актуальные файлы с GitHub, создаст резервную копию оригинала и установит русификацию.

### Установка из репозитория

```bash
git clone https://github.com/SPIDIKSY/antigravity-ru.git
cd antigravity-ru
powershell -ExecutionPolicy Bypass -File install.ps1 -Install
```

---

## Откат к оригиналу

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall
```

Скрипт восстановит оригинальный `app.asar` из резервной копии и удалит русифицированные ресурсы.

## Структура репозитория

```
antigravity-ru/
├── install.ps1                      # Установщик / деинсталлятор (поддерживает irm | iex)
├── patch.js                         # Открытый код всех патчей к app.asar (для аудита)
├── resources/
│   ├── app.asar                     # Локализованное ядро Electron
│   └── web_bundle_ru/               # Интерфейсный бандл
│       ├── i18n-ru.js               # Движок локализации (словарь + MutationObserver)
│       ├── index.html               # Точка входа веб-приложения
│       ├── jetbox.css               # Компактные шрифтовые стили
│       ├── dark.png / light.png     # Карточки предпросмотра тем
│       └── main.js                  # Сборка интерфейса React SPA
├── README.md
├── LICENSE
└── .gitignore
```

## Что именно патчится в app.asar

Файл `patch.js` содержит полный исходный код всех изменений — можно прочитать и убедиться, что ничего лишнего:

| Файл | Что изменено |
|------|-------------|
| `dist/languageServer.js` | Подключение `web_bundle_ru` вместо стандартного бандла |
| `dist/menu.js` | Перевод системного меню окна (Файл, Правка, Вид...) |
| `dist/tray.js` | Перевод контекстного меню трея и счётчика агентов |
| `dist/main.js` | Перевод диалогов выхода и пунктов трея |
| `dist/updater.js` | Отключение фоновых автообновлений |
| `dist/loadingOverlay.js` | Перевод экрана предзагрузки |
| `dist/ideInstall/wizardHtml.js` | Перевод мастера установки |

2. Запустите установщик заново:
   ```powershell
   irm https://raw.githubusercontent.com/SPIDIKSY/antigravity-ru/main/install.ps1 | iex
   ```
