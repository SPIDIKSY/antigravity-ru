# 🇷🇺 Google Antigravity 2.0 — Полная русская локализация

Качественная, полная и компактная русификация интерфейса десктопного приложения **Google Antigravity 2.0** (Windows).

---

## ✨ Что переведено и оптимизировано

* **715+ терминов и фраз интерфейса:**
  * Все вкладки и параметры настроек: *Общие, Приложение, Внешний вид, Модели и лимиты, Браузер, Настройки, Уведомления, Аккаунт*.
  * Выпадающее меню профилей безопасности (*По умолчанию, Полный доступ к системе, Режим Турбо, Пользовательский*).
  * Статистика расхода токенов на навыки, правила и MCP (*динамический подсчёт и раскрывающиеся списки*).
  * Настройки и правила управления браузером (*Actuation Permissions*).
  * Все плейсхолдеры поиска и полей ввода (*«Поиск настроек...»*, *«Поиск флагов»*, *«Поиск по всем диалогам...»* и др.).
* **🖥️ Системные меню Electron:** Меню окна *Файл, Правка, Вид, Окно, Справка*, контекстное меню трея и диалоги выхода.
* **⏳ Сплеш-экран запуска:** экран предзагрузки заменён на *«Загрузка Antigravity...»*.
* **📐 Адаптированная типографика:** формулировки лаконичны и компактны, исключены раздутые переносы строк на кнопках и бейджах.
* **🛡️ Сохранение данных:** русификация основной версии не затрагивает ваш профиль — все проекты, история диалогов, ключи API и логины остаются нетронутыми.
* **🔒 Защита от автообновлений:** фоновый модуль `autoUpdater` отключён, поэтому Google не затирает русификацию в фоне.

## 🚀 Быстрый старт (Установка в 1 клик)

### Вариант 1: Через Git (для разработчиков)

```bash
git clone https://github.com/<ваш-аккаунт>/antigravity-ru.git
cd antigravity-ru
install.bat
```

### Вариант 2: Без Git

1. Скачайте репозиторий как ZIP-архив (`Code` → `Download ZIP`) и распакуйте в любую папку.
2. Запустите двойным кликом **`install.bat`**.
3. В открывшемся окне выберите вариант установки:
   * **`[1] Русифицировать ОСНОВНУЮ версию Antigravity (Рекомендуется)`**
     * Применяет русификацию прямо в вашу рабочую программу `%LOCALAPPDATA%\Programs\antigravity`.
     * Сохраняет все ваши проекты, чаты, профиль и создаёт резервную копию для безопасного отката.
   * **`[2] Создать ОТДЕЛЬНУЮ тестовую версию (Antigravity RU)`**
     * Создаёт изолированную копию в `%LOCALAPPDATA%\Programs\antigravity_ru` со своим независимым профилем и ярлыком на Рабочем столе.
4. Перезапустите Antigravity. Готово!

## 🔄 Как вернуть оригинал (Откат)

Если вы захотите вернуть официальную английскую версию:
1. Запустите файл **`uninstall.bat`**.
2. Скрипт мгновенно восстановит оригинальный `app.asar.original_backup` от Google и удалит русифицированные ресурсы.

## 📁 Структура репозитория

```text
antigravity-ru/
├── install.bat                      # Запуск установщика в 1 клик
├── install.ps1                      # Универсальный PowerShell-скрипт установки
├── uninstall.bat                    # Быстрый откат к официальному оригиналу
├── uninstall.ps1                    # Скрипт отката
├── resources/
│   ├── app.asar.main_app            # Локализованное ядро Electron для основной версии
│   ├── app.asar.isolated            # Локализованное ядро для тестовой версии (Antigravity RU)
│   └── web_bundle_ru/               # Интерфейсный бандл
│       ├── i18n-ru.js               # Движок локализации (словарь + MutationObserver)
│       ├── index.html               # Точка входа веб-приложения
│       ├── jetbox.css               # Компактные шрифтовые стили
│       ├── dark.png / light.png     # Карточки предпросмотра тем
│       └── main.js                  # Сборка интерфейса React SPA
└── src/                             # Исходные скрипты сборки
    ├── compile_i18n.js              # Генератор базы переводов
    └── patch_asar.js                # Скрипт пересборки ядра под новые версии
```

## 🛠️ Разработчикам: Как обновить при выходе новой версии от Google

Если Google выпустит крупное обновление Antigravity (например, 2.1 или 3.0):
1. Дайте приложению обновиться официально.
2. В папке `src/` запустите `node patch_asar.js`.
3. Запустите `node compile_i18n.js`.
4. Запустите `install.bat`.
