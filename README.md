# Google Antigravity — Полная русская локализация

Качественная, полная и компактная русификация интерфейса десктопного приложения **Google Antigravity** (Windows).  
Протестировано на версии **2.11.0**.

---

## Установка одной командой

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/SPIDIKSY/antigravity-ru/main/install.ps1 | iex
```

Скрипт автоматически загрузит файлы с GitHub, создаст резервную копию и установит русификацию.  
Для отката к оригиналу запустите тот же скрипт и выберите «Удалить русификацию».

## Что переведено

- **715+ терминов и фраз интерфейса:**
  - Все вкладки настроек: Общие, Приложение, Внешний вид, Модели, Настройки, Браузер.
  - Профили безопасности, поведение агента, разрешения для файлов, сети, терминала и MCP.
  - Расход токенов: правила, навыки, инструменты MCP — с раскрывающимися списками.
  - Панель изменённых файлов: Незафиксированные, Изменения агента, Ветка.
  - Все плейсхолдеры поиска и полей ввода.
- **Системные меню Electron:** Файл, Правка, Вид, Окно, Справка, трей и диалоги выхода.
- **Сплеш-экран:** «Загрузка Antigravity...».
- **Компактная типографика:** лаконичные формулировки без раздутых переносов.
- **Данные не затрагиваются:** проекты, история, ключи API и логины на месте.
- **Автообновление отключено:** фоновый `autoUpdater` не затирает русификацию.

## Установка из репозитория

```bash
git clone https://github.com/SPIDIKSY/antigravity-ru.git
cd antigravity-ru
powershell -ExecutionPolicy Bypass -File install.ps1 -Install
```

---

## Откат к оригиналу

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall
```

Восстановит оригинальный `app.asar` из резервной копии и удалит русифицированные ресурсы.

## Структура репозитория

```
antigravity-ru/
├── install.ps1                      # Установщик / деинсталлятор (поддерживает irm | iex)
├── patch.js                         # Открытый код всех патчей к app.asar
├── resources/
│   ├── app.asar                     # Локализованное ядро Electron
│   └── web_bundle_ru/               # Интерфейсный бандл
│       ├── i18n-ru.js               # Движок локализации (словарь + MutationObserver)
│       ├── index.html               # Точка входа
│       ├── jetbox.css               # Компактные шрифты
│       ├── dark.png / light.png     # Карточки тем
│       └── main.js                  # Сборка React SPA
├── screenshots/                     # Скриншоты интерфейса
├── README.md
├── LICENSE
└── .gitignore
```

---

## Что патчится в app.asar

Файл `patch.js` содержит полный исходный код всех изменений:

| Файл | Назначение |
|------|-----------|
| `dist/languageServer.js` | Подключение `web_bundle_ru` |
| `dist/menu.js` | Перевод системного меню окна |
| `dist/tray.js` | Перевод трея и счётчика агентов |
| `dist/main.js` | Перевод диалогов выхода |
| `dist/updater.js` | Отключение фоновых автообновлений |
| `dist/loadingOverlay.js` | Перевод экрана предзагрузки |
| `dist/ideInstall/wizardHtml.js` | Перевод мастера установки |
